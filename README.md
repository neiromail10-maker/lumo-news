# lumo-news

Хмарний збирач новин для Lumo. Раз на годину GitHub Actions читає публічні стрічки (RSS, Telegram, календар) і оновлює гілку `data`:

- `pool-accum.json` — накопичувач новин за 96 год (лише заголовки, короткі описи, посилання);
- `released-history.json` — історія «Вийшли дані» (факт / прогноз / було);
- `status.json` — стан останнього збору.

Тут немає особистих даних. Lumo лише **читає** `data` і перевіряє кожен запис; нічого звідси не виконує.

`collector/core.js` згенеровано з Lumo (`node collector/build-core.js main.js`) — не редагувати вручну.
